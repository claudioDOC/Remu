## Installation (einmalig, ca. 2 Minuten)

Du brauchst **r2modman** und ein Profil für Lethal Company.

1. **Herunterladen:** rechts auf dieser Seite auf **Releases** klicken und bei der obersten Version die Datei **`Remu-v….zip`** herunterladen.
2. **r2modman öffnen**, dein Lethal-Company-Profil wählen.
3. Links auf **Settings** → Reiter **Profile** → **Import local mod** → die heruntergeladene Zip auswählen → **Import local mod** bestätigen.
4. Fragt r2modman nach **BepInExPack** oder **LethalLib**: einfach installieren lassen.
5. **Start modded** – fertig.

## Updates

Laufen **automatisch**. Beim Spielstart holt sich Remu neue Versionen selbst. Steht im Hauptmenü *„Remu wurde aktualisiert“*, das Spiel einmal schliessen und neu starten. Sonst musst du nichts tun.

## Wenn etwas nicht klappt

- **Alle in der Lobby** brauchen Remu – und nach einem Update einmal neu starten.
- Geht gar nichts: Zip aus den Releases nochmal wie oben importieren.
